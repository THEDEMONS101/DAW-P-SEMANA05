## 📖 Descripción

**FUEGO ARCADE** es una SPA (Single Page Application) desarrollada con **React + Vite** que implementa:

- **Arquitectura de componentes** con JSX
- **Props y Children** para el flujo de datos
- **CSS Modules** para el estilado con scope aislado
- **Client-Side Rendering (CSR)** validado con React DevTools
- **Métricas reales** persistentes con `localStorage`
- **3 juegos funcionales**: Tres en Línea (con IA Minimax), Memoria y Reflejos
- **Diseño cyberpunk** con efectos Matrix, neón y animaciones

## 🎮 Juegos incluidos

| Juego | Descripción |
|---|---|
| ❌ **Tres en Línea** | Duelo vs IA con algoritmo Minimax + poda Alfa-Beta (3 niveles) |
| 🧠 **Memoria Cuántica** | Encuentra pares de símbolos geométricos |
| ⚡ **Test de Reflejos** | Mide tu tiempo de reacción en milisegundos |

## 🛠️ Tecnologías utilizadas

- **React 18** + **Vite 5**
- **CSS Modules** (scoping automático)
- **Context API** (estado global)
- **localStorage** (persistencia)
- **Minimax + Alfa-Beta** (IA del tres en línea)
- **Canvas API** (efecto Matrix)
